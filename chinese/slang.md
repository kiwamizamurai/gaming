# 隠語、俗称

掲示板、出品名、記事の見出しで見かけた表現。意味は文脈からの推定が多い。確実なものと推定のものを分けて書く。

## 販売者がよく使う宣伝文句

| 表現 | 意味 |
|---|---|
| 现货顺丰发出 | 在庫あり、順豊で発送 |
| 预装天马G顺丰包邮 | 天馬G入り、順豊で送料無料 |
| 送收纳包 | 収納ポーチ付き |
| 全新未拆封 | 新品未開封 |
| 到手即玩 | 届いたらすぐ遊べる |
| 此链接不包含机器 | このリンクには本体を含まない |

## 注意

- 「预装天马G」は、ランチャーだけがプリインストールされているだけの場合もある。収録ゲームの内訳は、必ず出品者に確認する。
- 掲示板の投稿は、個人の経験談。誇張や、広告が混ざる。
- 隠語の意味が分からない場合は、百度で「<語> 什么意思」と検索する。
