# 隠語、俗称

掲示板、出品名、記事の見出しで見かけた表現。意味の確度を3段階で書く: 確認 = 複数の出典で用法が確認できた / 推定 = 文脈から推定 / 不明 = 意味を確認できていない。

## 販売者がよく使う宣伝文句

| 表現 | 意味 |
|---|---|
| 现货顺丰发出 | 在庫あり、順豊で発送 |
| 预装天马G顺丰包邮 | 天馬G入り、順豊で送料無料 |
| 送收纳包 | 収納ポーチ付き |
| 全新未拆封 | 新品未開封 |
| 到手即玩 | 届いたらすぐ遊べる |
| 此链接不包含机器 | このリンクには本体を含まない |
| 分期免息 | 分割払いの利子なし |

## 注意

- 「预装天马G」は、ランチャーだけがプリインストールされている場合もある。収録ゲームの内訳は、出品者に確認する。
- 掲示板の投稿は、個人の経験談。誇張や、広告が混ざる。
- 意味が分からない語は、百度で「<語> 什么意思」と検索する。
