# CSDNの天馬G記事

種類は、CSDNの個人ブログです。URLは https://blog.csdn.net/fanged/article/details/152960565 、題名は「天马G前端的使用」、記事の日付は2025年10月です。信頼度は個人で、筆者が自分の環境で試した手順が書かれています。ページを開いてすぐは本文が読み取れず、少し待ってから読みました。

## 内容

筆者は、使っていなかった小米9(Snapdragon 855)があり、コントローラーも手に入れたため、レトロ機を作る目的で書き始めました。最初に、市場の携帯機を、AndroidとLinuxの2種類に分けて、表で比べています。Androidは、起動が20〜40秒かかり、アプリごとに画面が違います。PS2はAetherSX2で動き、Switchは非公式版もあり、クラウドゲームとSteam Linkに対応する、という内容です。Linux系(ArkOS、JELOS、Batocera)は、起動が5秒以内で、画面が統一され、設定を自由に変えられる一方、BIOSとcoreの手動の設定が必要です。

PS2のエミュレーターがAndroidに偏る理由を、作者のTahlrethがAetherSX2をAndroid向けにだけ作り、Android NDKとVulkan/OpenGL ESでJITを実装したためと説明しています。JITは、元のゲーム機の命令を、動かしている機械の命令へ実行中に変換して、「ホットスポット」を最適化する技術です。

市場の機種として、安伯尼克のRG35XXがT700(1×2.5GHzのA76と3×2.3GHzのA76)、RG406VがT820(1×2.7GHzのA76と3×2.3GHzのA76)で、性能の向上は大きくないのに、価格は2〜3倍になった、と書いています。ただし、RG35XXをT700とする記述は、ROCKNIXの文書がRG35XXをH700の機種に分類していることと食い違います。RG406VのT820を4コアとする記述も、掌机圈の8コアという記載とは異なる内容です。数値は、筆者の誤りの可能性があるため、そのままは使えません。筆者は、手元の小米9が、T820よりCPUもGPUも大幅に上で、中古が約350元だったため、コントローラーを足してもRG406Vの半額だと計算し、自作に決めました。

導入は、APK、設定、ROMの3段階です。APKは、天馬G本体、RetroArch、各エミュレーター、ファイル管理のMT管理器で、筆者はadbで入れました。設定は、天馬Gの主題パックと設定ファイル、それに `Android` フォルダの3つです。Android 11以降では、各アプリのデータフォルダが保護されていて、天馬Gが、Pegasus、RetroArch、AetherSX2の間で設定とROMのパスを共有するため、事前の手動の配置が必要です。ROMは、ROMのファイルに加えて、主画像、副画像、紹介動画、メタデータが必要で、「跳坑者联盟」のパックでは、精簡包の中に用意されています。筆者は、ROMは敏感な内容なので、エミュレーターの制作者や工房は提供せず、国内では「跳坑者联盟」のパックが広く出回っていると書いています。

実際に動かすと、画面は華やかで、USB接続のコントローラーは遅延がほとんどなかったそうです。一方で、スマホの画面の形のために、4:3のゲームには左右に大きな黒い帯が入ります。PSPは、見え方がよいと書いています。

最後は、天馬Gの技術原理の説明です。天馬Gは、フロントエンドにすぎず、ROMの管理とエミュレーターの起動を担当します。実際の処理は、各エミュレーターのAPKに任せる仕組みです。公式サイトはhttps://pegasus-frontend.org/で、Qtで作られています。Androidの核心部分のコードは、`launchAmCommand` という関数です。この関数が `am start` のIntentを組み立て、JNIから `startActivity` を呼び出して、サードパーティのエミュレーターを起動します。筆者は、RetroArchを直接入れても遊べて、そのほうが簡単な場合もあると書いています。最後の「FPGAの拡張」の節は、エミュレーターの性能を、FPGAで上げられるかという将来の関心です。
