# 掌机圈の機種ページ

種類は、携帯ゲーム機の仕様のデータベースです。URLは、トップが https://zhangjiquan.com/ で、機種の一覧が https://zhangjiquan.com/handhelds です。信頼度は集約で、仕様の値は、サイトの運営者とユーザーの投稿に基づきます。各ページに「信息补充或纠错」(情報の補足や訂正)のボタンがあり、訂正の申請ができます。公式の仕様表ではないため、載っていない項目や、実際と違う値があり得ます。

## サイトの構成

上部のメニューは、掌机新闻和资讯(ニュース)、掌机图片(写真)、待发布游戏掌机列表查询(発売前の機種)、游戏掌机机型列表查询(機種の一覧)、上传掌机或游戏相关的贴图(貼り絵の投稿)です。機種のページには、仕様の表、同じ画面サイズ、同じアスペクト比、同じSoCの機種の一覧、ブランドの別の機種、2機種を並べた比較ページへのリンク、ユーザーの評価とコメント、購入リンク、実機写真があります。
