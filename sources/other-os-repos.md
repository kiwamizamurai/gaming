# Repositories of other OSes

The type is the GitHub repositories and official wikis of each OS. Reliability is official. Star counts and update dates were checked with the `gh` command on October 3, 2026.

## GammaOS Core

[GammaOS Core](https://github.com/TheGammaSqueeze/GammaOSCore) is a minimal Android 13 TV configuration based on LineageOS, intended for devices that use low-performance chips such as the Rockchip RK3566 and do not need a touchscreen. It includes modifications that reduce memory use and improve usability. The license is Apache-2.0, and the last update was in February 2025.

The supported devices are Anbernic (RG ARC-D/S, RG353V/VS, RG353P/PS, RG353M, RG503), Powkiddy (RGB30, RGB20SX, RGB10MAX3, RGB20 PRO, X55, X35H, X35S), GameMT (E5 Plus, E6 Plus), GKD (Bubble), others (CB408, Miyoo Flip), TrimUI (Smart Pro), and MagicX (Zero28). Its features are booting from an SD card (the system on the internal eMMC can be kept), preconfigured RetroArch and the launcher Daijisho, MiXplorer, support for rooting and Magisk, quick settings opened by long-pressing the power button, mouse emulation used by long-pressing Select and R1, Bluetooth audio, USB MTP, improved CPU and GPU performance, improved battery life, relaxed file access restrictions (scoped storage), and HDMI output settings.

## ArkOS and JELOS

[ArkOS](https://github.com/christianhaitian/arkos) is described as "Another rockchip Operating System", and its README leaves details and image links to the [Wiki](https://github.com/christianhaitian/arkos/wiki). The last update was in August 2025, with about 2150 stars. [JELOS](https://github.com/JustEnoughLinuxOS/distribution) is described as "Home of the JELOS Linux distribution", with its last update in May 2024 and about 950 stars. The ROCKNIX README describes ROCKNIX as a fork of JELOS.

## muOS

The repositories of the [MustardOS](https://github.com/MustardOS) organization include frontend (`frontend`), internal (`internal`), assets (`asset`), themes (`theme`), website (`mustardos.github.io`), tools (`tool`), languages (`language`), extras (`extra`), terminal (`terminal`), and file manager (`vtree`). The website repository has data on supported devices (RG28XX-H, RG34XX-H, RG34XX-SP, RG35XX 2024, H, Plus, Pro, SP, RG40XX-H, V, RG CubeXX-H, and TrimUI's Brick and Spoon) and descriptions of each feature. The official site muos.dev could not be read by the browser used in this research.

## LineageOS

The [official LineageOS Wiki](https://wiki.lineageos.org/devices/RPN) has a page for the Retroid Pocket Nova. It shows the codename "RPN", the SoC "Qualcomm Dragonwing QCS8550", 8 or 12GB of LPDDR5 RAM, a Kryo CPU at 1×3.2GHz, 4×2.8GHz, and 3×2.0GHz, an Adreno 740 GPU, and a release in July 2026. The page links to installation steps, building it yourself, updates, special boot modes (pressing volume down and power together enters recovery mode and the bootloader), and known issues (device integrity).
