# examples

These are minimal examples of homemade games. For both, the article [How to make your own games](../articles/14-making-games.md) explains how they are made and how to check that they work.

[love2d-coin](love2d-coin) is a coin-collecting game that runs on LÖVE 11.5. It does not need a ROM. Start it with `love examples/love2d-coin`.

[gbdk-coin](gbdk-coin) is a Game Boy ROM built with GBDK-2020 4.5.0. `make GBDK_HOME=$HOME/gbdk` produces `coin.gb`. Place GBDK somewhere with a short path.

[love2d-coin-plus](love2d-coin-plus) is an extended version of the LÖVE game that adds tile graphics, a map with walls, sound effects, and saving the high score. The graphics and sound effects are generated by `make_assets.py`. Start it with `love examples/love2d-coin-plus`.

[gbdk-coin-plus](gbdk-coin-plus) is an extended version of the GBDK game. It adds tile graphics, a map with walls, sound effects, and saving the high score to battery-backed RAM. `make GBDK_HOME=$HOME/gbdk` produces `coin_plus.gb`.

[rea-lab](rea-lab) contains the files used in [article 22](../articles/22-rea-hands-on.md) through [article 24](../articles/24-android-nova.md). It includes C, Python, C# (two versions), JavaScript (two versions), and LÖVE versions of the coin-collecting game, Ghidra scripts, and steps for reading the Android APK of LÖVE with REA. Details are in [rea-lab/README.md](rea-lab/README.md).

[agb-counter](agb-counter) is a counter for the Game Boy Advance in Rust, built with agb. A adds 1, B subtracts 1, and START resets it. See [article 26](../articles/26-gba-rust-setup.md). The font in `assets` is under the SIL Open Font License (`assets/OFL.txt`).

[link-demo](link-demo) is two small Rust files for watching a linker join object files. See [article 30](../articles/30-rust-to-gba-rom.md). To build it on a Mac: `rustc --edition 2024 --crate-type=lib --emit=obj -C panic=abort -C opt-level=1 counter.rs`, the same for `game.rs`, then `cc game.o counter.o -o demo`.
