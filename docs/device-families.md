# ブランドと機種のカタログ

主なブランドと機種を整理する。出典は、ROCKNIX公式Wiki(確認)と、什么值得买、百度の検索結果(記事)。記事の抜粋は、検証していない。什么值得买の「2026开源掌机红黑榜」はAIGC(AI生成)と表示されており、数値の信頼性は低い。

## ブランド

| ブランド | 中国語 | 特徴(記事の記述) |
|---|---|---|
| Anbernic(RG) | 安伯尼克、周哥 | 深圳の会社。2017年にIPS画面のRG350を出した。ラインナップが最も広い。金属ボタン、金型の質感、Wi-Fi対戦。純正OSの最適化不足で、第三方CFWを入れる人が多い |
| Miyoo | 米优 | 小型。Mini系は煙草の箱サイズで200元以内。生産量が少なく、愛称は「猴里谢」(記事) |
| GKD | 老张 | OSの最適化がよい。メンテナンスが3〜4年続く。生産量が少なく、中古に割増が出る |
| Powkiddy | ROCKNIXが多数の機種に対応している(X55、RGB30など)。RGB30はCortex-A55 4コア 1.8GHz(百度知道)。GammaOSCoreというカスタムOSが、RGB20 PRO、X55に対応している(GitHubのリリース一覧) |
| TRIMUI | Smart Pro、Brickなどがある |
| Retroid | Android機が中心。Pocket 5、6、Flip2、Mini、Nova。Batoceraの公式ビルドがMini、Mini V2、5、Flip 2、6にある |
| AYN | Odin 2、Odin 2 Mini、Odin 2 Portal、Thor、Odin 3。Odin 2は2023年8月に1999元からと発表され、Snapdragon 8 Gen 2を搭載(IT168)。Odin 2 MiniはPS Vita風の外観で、2024年6月末から出荷(百度百科) |
| AYANEO | Pocket ACE、DMG、EVO、DS、S2。Pocket AIR Miniは2025年9月に499元から予約開始(超能网) |
| GameForce | Ace。RK3588S搭載。2024年2月5日に出荷開始(当時、RK3588Sを載せた唯一の量産掌機、機核の記事) |

## 縦型と横型

- 縦型: RG40XXV、RG406V、TRIMUI Brick Proなど。GBや携帯機のような握り心地
- 横型: RG40XXH、Retroid Pocket 5、RP4 Pro、RG556など
- 老张GKDは、縦型設計が人間工学を犠牲にしているという評価がある(記事)
