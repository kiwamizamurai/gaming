# ポケモンの改造(ROM hack、改版)

中国では「口袋妖怪改版」(ポケモンの改造版)と呼ばれ、掲示板や配布サイトが大きな文化になっている。出典は、百度の検索結果と各記事の抜粋。内容は個別に検証していない。

## 方法の分類

| 方法 | 内容 |
|---|---|
| パッチを当てる | 作者が公開したパッチ(IPS/BPS/UPSなど)を、元のROMに適用する。完成品の改造版を遊ぶ最も簡単な方法 |
| ROMを直接編集する | HexManiacAdvance、Advance Map、XSEなどのツールで、データ、地図、スクリプトを書き換える |
| ソースから作る | 逆アセンブル、逆コンパイルされたソースを、ビルドして作る。最も自由度が高い |
| チートコード(金手指) | 実行中のメモリを書き換える。零元購(0円で買える)、最大種族値、壁抜けなど |
| セーブデータ編集 | PKHeXなどでポケモンやアイテムを書き換える |

## ソースから作る(pret系の逆コンパイルプロジェクト)

百度の検索結果にあった、pretのGitHub概要:

| プロジェクト | 内容 |
|---|---|
| pokered | 赤・青の逆アセンブル(アセンブリ) |
| pokecrystal | クリスタルの逆アセンブル(アセンブリ) |
| pokeemerald | エメラルドの逆コンパイル(C言語) |
| pokeplatinum | プラチナ(公開リポジトリあり) |
| pokefirered | ファイアレッド/リーフグリーンの逆コンパイル |
| pokeemerald-expansion | rh-hideoutチームの拡張。新しいポケモンや機能を追加できる |

- bilibiliの制作記録(2024年2月)では、「蓝本」(ベース)にpokeemerald-expansionを使い、ツールとして Visual Studio Code、AGBCCコンパイラ、Ubuntu 22.04、Photoshop、Advance Map 1.92を挙げていた。中国語のテキストとフォントは、別の人の汉化データを使っている。
- 地図エディタ: Porymap(pokeruby、pokeemerald、pokefireredに対応)。公式ガイド https://huderlem.github.io/porymap/

## ROMを直接編集する(GBA)

| ツール | 内容 |
|---|---|
| HexManiacAdvance | オープンソース(C#、.NET 6.0)。ポケモンGBAのテーブル、テキスト、スクリプト、画像などを編集する。Ruby、Sapphire、FireRedなどに対応(CSDN記事) |
| Advance Map(AM) | 地図とイベントの編集 |
| FSF | ROM内の空き領域を探す |
| XSE | スクリプトエディタ |
| WinHex | バイナリエディタ(2015年の貼吧の教程) |
| PKHeX | ポケモンのデータやセーブの編集(CSDN文库の記事) |

百度知道の手順の要約(2025年11月):

1. 原版のROMを用意する(自分で正規に用意したもの)
2. AMでROMを読み込み、地図とイベントを編集する
3. FSFで空き領域を探して、新しい内容を追加する
4. XSEでスクリプトを書き、NPCの会話を作る

## 注意

- 配布サイトには、「パッチ適用済み」のROMを配布しているところがある。原作ROMの再配布にあたり、権利面で問題がある。パッチ(差分ファイル)だけを入手し、自分で用意した原版ROMに当てる方式が安全。
- ROM、ツールの配布リンクは、このリポジトリには記録しない。
- ツール配布の一部は、AIによる自動生成のダウンロードページ(「智能分身」と表示されるもの)で、中身が確認できない。安全性が不明なので、避ける。

## 学べること

- アセンブリとC言語、逆コンパイルの仕組み
- ROMのデータ構造(テーブル、ポインタ)
- Gitで管理して、ビルドして、パッチを作る流れ
- 地図(タイルセット)、スクリプトの言語(イベント)
- 中国語のテキストとフォント(汉化)の入れ方
