# カスタムファームウェア(CFW)の比較

Anbernic H700機種などに入れる、第三方のOS。出典は、百度の検索結果の抜粋と、什么值得买、百度貼吧、百度文库の記事。個人の感想を含み、確認できていない。

## 主なCFW

| 名前 | 対象 | 特徴(記事の記述) |
|---|---|---|
| muOS | Anbernic H700機種 | RetroArch優先、起動が速い。シンプル |
| Knulli | Anbernic H700機種ほか広く対応 | ボックスアート表示、RetroAchievements、OTA更新。見た目が華やか。テーマが多く、ゲームリストに画像を付けられる |
| ROCKNIX | H700、RK3326、RK3566、Snapdragon系など | 機能が多い。2026年6月の安定版でSteam、Vita3Kが追加され、対応機種が49から66に増えたという記述がある(AIGC記事) |
| ArkOS | Rockchip系(RG351、R36Sなど) | 動作が滑らか。進階者向け |
| JELOS | Rockchip系 | ArkOSと並ぶ人気。ゲームフォルダを削除しても、再起動で再生成されるなどの違いが、掲示板にある |
| OnionOS | Miyoo Mini系 | 最も洗練された入門向けOSとされる |
| EmuELEC | Amlogic系のAndroid TVボックスなど | 設定が簡単で最適化がよいとされる |
| Batocera | Raspberry Piなど | プラグアンドプレイで初心者向けとされる |
| RetroPie | Raspberry Pi | コミュニティの情報が最も多いとされる |

## 掲示板での評価(百度貼吧、個人の意見)

- 「Knulliは、muOSより華やかで、テーマが多く、ゲームリストに画像を付けられる」
- 「RG40XXVのmuOSは起動が速い。Knulliより速く、周哥の公式システムよりはるかに速い。オンラインでPort Masterが使える」
- 「CubeXXにKnulliを入れたが、最適化が悪く、純正より劣る。花瓶のようなシステムで使いにくい。素直に公式の魔改システムを使うほうがよい」(2025年8月、2件の返信)
- 「周哥の公式システムでは、Bluetoothイヤホンが使えない」(開源掌機吧の投稿)

評価は機種とバージョンで変わる。古い投稿は参考程度に。

## OS選びの指針(百度文库、什么值得买の記事より)

- 手元の機種の型番を確認してから、OSを選ぶ。同じ名前の機種でも、ARMとx86の2種類があることがある。違うOSを書くと、動かなくなる(「变砖」)。
- 2026年の主流の開源掌機は、90%がRockchipチップとされる記述がある。H700とRK3326が半分を占める。
- 懐かしいゲーム(FC、GBA、PS1)だけで、手間をかけたくなければ、公式システムかEmuELECが安全。
- 技術が好きで、テーマや設定を調整したいなら、ArkOSかJELOSが向く。
- PS2、Wiiのような高度なエミュレーションなら、Android機が向く。

## 公式システムの更新手順(H700機種、什么值得买、2025年2月)

1. システムカードの `roms` と `save` フォルダを、PCにバックアップする
2. 機種に対応するシステムパッケージをダウンロードして解凍する
3. 書き込みソフトでカードをフォーマットして、新しいシステムを書き込む
4. 書き込み完了を待ち、システムの設定を行う
5. バックアップした `roms` と `save` を、カードに戻す

オンラインでゲームをダウンロードするアプリを使う場合は、Wi-Fiに接続しておく。未接続だと、画面が黒くなる問題が起きる、とある。

## 手順のイメージ

| CFW | インストールの流れ |
|---|---|
| ROCKNIX(H700) | イメージをSDカードに書き込む、DTBを `dtb.img` にコピー、起動(docs/rocknix-guide.md) |
| ROCKNIX(Retroid Pocket 5) | SDカードへの書き込み、Android側でABL書き換え、ブートモードをLinuxにする(docs/rocknix-guide.md) |
| muOS、Knulli | SDカードにイメージを書き込む方式が一般的。公式サイトを参照(この調査では公式ページを開けなかった) |

## リスク

- システムの崩壊、データの損失、起動不能の可能性がある(記事の注意書き)。事前にバックアップし、機種に合ったパッケージを使う。
- 保証が無効になる可能性がある。
- 販売者によっては、「魔改」システムをすでに入れた状態で売っている。純正に戻す方法を確認しておく。

## 学べること

- Linuxの起動の仕組み(ブートローダ、デバイスツリー)
- ファイルシステム(FAT32、exFAT、ext4)の違い
- エミュレーターのcoreとフロントエンドの関係
- OTA更新、イメージの書き込み、バックアップの習慣
