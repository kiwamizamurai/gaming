# 改造できること

ハードウェアとソフトウェアの改造を、分野別に整理する。出典は、百度の検索結果と各記事の抜粋。個別の手順は、検証していない。

## ソフトウェア

| 改造 | 内容 | 対象 |
|---|---|---|
| OSの入れ替え | ROCKNIX、Knulli、muOS、ArkOS、JELOSなど(docs/custom-firmware.md、docs/rocknix-guide.md) | H700、RK3326系など。Retroid Pocket 5はROCKNIX |
| Batocera | Retroid Pocket Mini、Mini V2、5、Flip 2、6向けのビルドが公式にある(batocera.orgのダウンロード一覧) | Retroid |
| フロントエンド | 天馬G、EmulationStation、ES-DE | Android、Linux |
| テーマ | 天馬Gは8テーマ内蔵(記事)。ROCKNIXにもthemesのページがある | 全般 |
| スクレイパー | ゲームのカバーや紹介を自動で取得する(ROCKNIXのconfigure/scraper) | ROCKNIX |
| シェーダー、オーバーレイ | CRTフィルターなどの画質調整(ROCKNIXのconfigure/shaders、overlays) | RetroArch |
| 内部解像度 | PSPを2倍以上にして画質を上げる(百度AI要約) | PPSSPPなど |
| 主題パックと設定ファイル | 天馬Gの主題パックと設定(CSDN記事) | 天馬G |
| メタデータの追加 | 天馬Gのゲームのカバーと中国語名を追加(百度AI要約) | 天馬G |
| ゲーム管理ツール | 天馬Gのゲーム追加を簡単にするPython製ツールの事例がある(什么值得买、2026年1月) | 天馬G |
| オーバークロック | RG40XX Hは、ROCKNIXの設定で1.5GHzが選べる(ROCKNIX公式) | RG40XX H |
| ファームのOTA、更新 | 公式OTAで更新(RP4 Proの例) | Retroid |
| root化 | XDA ForumsにRP4 Proのroot化スレッドがある | RP4 Pro |
| Linuxへの切り替え | Retroid Pocket 5は、公式にLinuxを載せられる(発売時の記事:BatoceraやArmbianを入れられる、カーネルソースが公開) | RP5 |
| 自作のOS | LoongOS(Linuxベース、2026年の記事)など、メーカー独自のOSもある | 一部機種 |

## ゲームの改造

- ポケモンなど: docs/pokemon-hacking.md
- GBA、アーケードのROM hack: 百度貼吧、CSDNに教程(街机游戏HACK ROM制作与教程、GBA Hack怎么用)
- 合卡(複数ROMを1つにまとめる)の手順: Stage3rdの論壇の「GBA合卡 小白图文教程」
- チートコード(金手指): 零元購、最大種族値、壁抜けなど

## ハードウェア

| 改造 | 内容 | 出典 |
|---|---|---|
| 放熱 | RG40XXHの放熱改造の投稿。「シリコン放熱パッドを置くのが簡単」という返信がある | 百度貼吧 |

## 改造の優先順位の目安

1. **ソフト**: テーマ、フロントエンド、スクレイパー、シェーダー(失敗しても戻せる)
2. **OS**: CFWの入れ替え。事前にバックアップ(docs/custom-firmware.md)
3. **ハード**: 放熱パッド、スティックキャップなど、外装の交換
4. **分解**: 基板の改造、電池の交換(リスクが高い。保証が無効になる)

## 注意

- OSの書き換えとハードの改造は、故障と保証失効の可能性がある。
- 改造済み(魔改)の機体は、出品者の改造内容を確認する。
- 高額の「魔改」出品は、割高な場合がある(PSPの事例)。

## 学べること

- ブートローダ、デバイスツリー、ファームウェア
- 熱設計(放熱パッド、ヒートパイプ)
- 電池と充電の基礎
- 3Dプリントと、外装の設計
- Linuxの設定ファイルと、起動スクリプト
