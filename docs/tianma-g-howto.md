# 天馬G 手順メモ

百度の検索結果(百度文库、百度貼吧、百度知道、知乎、bilibili、CSDN)と、読んだ2つの記事の抜粋から、手順を整理したもの。個人の記述で、実機では試していない。ROMの入手には触れない。

## 構造

- 天馬G: Pegasusベースの中国語版フロントエンド
- 各機種(プラットフォーム)ごとのフォルダに、`metadata.pegasus.txt` がある(百度文库)。ゲーム一覧と起動コマンドが書かれている。
- 起動コマンドは、RetroArchの実行ファイルのパスと、使うcoreを指定する(百度文库)。
- coreは、RetroArchのオンラインアップデーターで、必要なものをダウンロードする(百度文库)。

## ゲームを追加する手順(百度文库、2026年9月)

1. ゲームのファイルを、機種のフォルダに置く
2. PCやスマホのテキストエディタで、機種フォルダの `metadata.pegasus.txt` を開く
3. 末尾に、新しい記録を追加する。主なフィールド:
   - `game:` ゲームの表示名(中国語でもよい)
   - `file:` ファイル名(拡張子を含み、手順1のファイル名と完全に一致させる)
   - `developer:` 中国語化チームやバージョンの情報など(任意)
4. カバー画像やメディアは、assetsの設定でパスを指定する(貼吧の返信に「assetsの設定を加えれば、パスは自分で指定でき、プレビューのメディアフォルダ…」とある)

`metadata.txt` の例(知乎、2022年の記事の抜粋):

```
collection: 3DO
extension: bin, iso, zip
ignore-file: D no Sho...
```

(途中で切れている。`collection` が機種名、`extension` が対象の拡張子、`ignore-file` が除外するファイルを表すとみられる。)

## 機種を追加する(百度知道、2025年8月)

1. 機種用のフォルダを作る
2. `metadata.pegasus.txt` を新規作成し、機種とゲームの情報を書く
3. RetroArchを起動して、対応するcoreを呼び出す
4. ロゴを表示するには、テーマ(pegasus-theme-grid)の `assets/logos` に、機種名と同じ名前の画像を置く(2020年の記事)。ロゴがない場合は、自作の画像を置いてもよい。

## Androidでの初期設定(検索結果の導入ページ、2025〜2026年)

1. アプリを開く。「すべてのファイルを管理する」権限が求められるので、許可して戻る
2. 再度開き、写真・動画・音楽へのアクセスを求められたら、許可する
3. ホームの初期の「ソース」には、Androidアプリも含まれている

CSDNの記事(Android 11以上)では、各アプリの `Android/data` が保護されているため、設定ファイルは、あらかじめ手動で配置する必要があるとされる。

## PC版のトラブルシューティング(百度文库)

- PSPのゲームが表示されない場合の7ステップのうち、「ウイルス対策ソフトを一時的に切る、またはインストールフォルダ全体を信頼リストに追加する」「`metadata.pegasus.txt` が壊れていないか確認する」が挙げられている
- 知乎の記事: 起動時に音が出ない、Wiiで閉じる場合は、ランタイムやドライバを入れる(3DM運行库など)

## 別のCFWの導入手順(検索結果から)

### muOS(bilibili、2025年6月)

1. システム用のSDカードを、PCに挿す
2. Rufusで、SDカードとmuOSのイメージを選び、開始する
3. 書き込みが終わったら、システムカードと、空のデータカードを、掌機に挿す
4. 電源を入れて、muOSのインストールが終わるのを待つ
5. 初期ホームが表示されたら完了

### OnionOS(CSDN、2026年1月、Miyoo Mini向け)

1. SDカードを、Large FAT32でフォーマットする(Windowsは Rufus、MacはMS-DOS(FAT))
2. 配布ページから、最新の `Onion-v4.x.x.zip` を取得して、解凍する
3. ファイルをSDカードにコピーする

### RG34XXの再インストール(百度文库、2026年6月)

- Balena Etcherでイメージを書き込む
- 起動しなくなった場合: カードを作り直す、別のTFカードとリーダーを使う、それでもだめなら、USB書き込みモード(分解が必要な場合がある)

### Knulli(GitHubのissue、2025年12月)

- RG40XXH/Vで、スリープから復帰したとき、画面が真っ黒になる、縦の筋が出る、という報告がある(ファイルシステムはexFAT)。

## 学べること

- フロントエンドと、エミュレーター本体の役割分担
- 設定ファイル(`metadata.pegasus.txt`)の書式
- ファイルの権限と、Androidのデータ領域の制約
- SDカードの書き込み(Rufus、Balena Etcher)、フォーマット(FAT32、exFAT)
